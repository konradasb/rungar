# Roadmap

This document outlines the high-level direction for Rungar. It is not a
commitment or a schedule — priorities shift with real-world usage.

For detailed tracking, see the [GitHub Issues](https://github.com/konradasb/rungar/issues)
and [Milestones](https://github.com/konradasb/rungar/milestones).

---

## Current focus

Rungar is one daemon that keeps GitHub Actions runner scale sets supplied
with runners, each a VM, across its providers. The current focus is on making
that work reliably, and with a good user experience.

## How to influence the roadmap

- Open an [issue](https://github.com/konradasb/rungar/issues/new) to propose a
  feature or share a use case
- Comment on existing issues to signal demand
- Submit a pull request — working code is the fastest path to inclusion

Maintainers review roadmap items periodically. Community interest and
real-world usage are the primary drivers of prioritisation.
